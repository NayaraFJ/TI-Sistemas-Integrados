# Projeto Overleaf — TI SIGE

O projeto usa a formatação do modelo em `../../Ref Overleaf` e consolida o conteúdo de `../Trabalho` em um único trabalho científico.

## Atualização do conteúdo

Use `TI/Trabalho` como fonte. Ao alterar essa base, incorpore a mudança de forma editorial em `conteudo.tex` e atualize as entradas citadas em `bibliografia.bib`. A compilação será feita pelo usuário no Overleaf; localmente, valide apenas a coerência dos arquivos-fonte. As etapas da disciplina são fontes de conteúdo, não títulos do trabalho final.
