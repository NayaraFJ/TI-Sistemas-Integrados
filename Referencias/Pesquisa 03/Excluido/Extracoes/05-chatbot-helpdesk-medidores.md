# Chatbot Helpdesk for Centralized Meter Record Application (ACMT) by PLN Using Deep Learning

- **Autores:** Dari Suparno; Domy Kristomo; Widyastuti Andriyani.
- **Ano:** 2025.
- **DOI:** `10.1109/ICoCSETI63724.2025.11019923`.
- **Relevância:** **2/5**.

## Síntese

Desenvolve chatbot com *deep learning* para responder a dúvidas de operadores de leitura de medidores. Utiliza dados de ITSM para criação de intenções e reporta métricas de acurácia do modelo e dos testes automatizados.

## Motivo do descarte

O artigo é uma alternativa de automação por IA para suporte técnico de concessionária. Chatbot, classificação de intenções e integração com dados de ITSM não fazem parte do MVP do SIGE Desk; sua inclusão ampliaria indevidamente o escopo.
