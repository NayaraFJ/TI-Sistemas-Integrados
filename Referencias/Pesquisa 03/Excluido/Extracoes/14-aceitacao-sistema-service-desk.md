# The User Acceptance of Service Desk Application System Description

- **Autores:** Muhammad Qomarul Huda; Rinda Hesti Kusumaningtyas; Bella Marisela Caroline.
- **Ano:** 2018.
- **DOI:** `10.1109/CITSM.2018.8674283`.
- **Relevância:** **2/5**.

## Síntese

Pesquisa com UTAUT sobre aceitação de um sistema de Service Desk em universidade. O contexto relatado mostra que parte dos usuários ainda preferia procedimentos manuais, reforçando a importância da aceitação na implantação de sistemas.

## Motivo do descarte

É pertinente como alerta de adoção, mas o artigo já utiliza avaliação de usabilidade com UEQ-S e fonte metodológica específica. O estudo universitário não é necessário para fundamentar o problema nem os requisitos do MVP.
