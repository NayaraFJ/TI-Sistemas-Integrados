# Organização dos materiais de trabalho

Esta pasta separa a fonte acadêmica que compõe o artigo da documentação técnica do projeto. A separação evita transportar inventários técnicos para o corpo do texto acadêmico e define uma fonte canônica para cada assunto.

## Artigo

Os arquivos em [Artigo](Artigo/README.md) são as fontes de conteúdo para `../Overleaf`. Eles fornecem, de forma complementar, resumo, introdução, problema, objetivos, referencial teórico e metodologia. O Overleaf deve sintetizá-los como artigo contínuo; não deve reproduzir os títulos de etapa nem repetir listas extensas.

## Documentação do projeto

Os arquivos em [Documentacao do Projeto](Documentacao%20do%20Projeto/README.md) registram processo, protótipo de baixa fidelidade e especificação completa. Eles são a fonte dos apêndices e das sínteses apresentadas no artigo, mas não devem ser copiados integralmente para o corpo do artigo.

## Regra de manutenção

1. Altere o arquivo canônico do assunto antes de alterar uma cópia histórica.
2. Ao mudar conteúdo acadêmico, atualize o trecho correspondente do `Overleaf` na mesma tarefa.
3. Quando a informação detalhada já estiver em outro arquivo, use um link em vez de duplicá-la.
4. Mantenha o artigo e a documentação semanticamente coerentes, mas preserve a diferença de propósito: o artigo analisa e sintetiza; a documentação especifica e evidencia.
