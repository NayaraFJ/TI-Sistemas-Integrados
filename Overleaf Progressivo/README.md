# Projeto Overleaf Progressivo — TI SIGE

Esta versão contém somente a entrega inicial: capa, contracapa, resumo, abstract, sumário, introdução e referências citadas na introdução. As próximas seções serão acrescentadas progressivamente.

Ao editar a introdução, mantenha `conteudo.tex` e `bibliografia.bib` coerentes: toda citação deve possuir uma referência, e nenhuma referência não citada deve permanecer nesta entrega.
